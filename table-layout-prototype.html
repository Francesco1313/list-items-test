List items strategy

Strategy 1

Title wraps up to 2 lines

  • Title column is wider. Text wraps up to 2 lines. Row height adjusts naturally to fit content.
  • Titles exceeding 2 lines are truncated with ellipsis and show full text on hover via tooltip.
  • Tags column is narrower. Chips truncated at ~18 characters with tooltip on hover showing full label.
  • The date and time are shown on two lines — the date on top, the time below in a smaller, lighter label. This keeps each date column narrower and leaves more horizontal space for the title.
  • Variable row height — rows are not uniform in height across the table. ⚠ risky
i As an alternative, all rows can have a fixed height slightly taller than the current default, so the layout stays consistent regardless of title length.
Variable row height risk: Row heights differ row-by-row depending on title length. This can make the table feel visually uneven and hard to scan at a glance.

Strategy 2

Fixed row height — single-line title

  • All rows share a fixed height. No row ever grows taller than this.
  • Title column is wider. Text stays on one line. Truncated titles show full text on hover via tooltip.
  • Tags column is narrower. Chips truncated at ~18 characters with tooltip on hover showing full label.
  • The date and time are shown on two lines — the date on top, the time below in a smaller, lighter label. This keeps each date column narrower and leaves more horizontal space for the title.
  • If the title column is still too narrow, the tooltip becomes the primary reading mechanism for that data. ⚠ risky
Tooltip-as-primary-reading risk: When many titles are truncated, users must hover each row to understand what they're looking at. This is especially painful on touch devices where hover is unavailable, and reduces scannability for power users.
