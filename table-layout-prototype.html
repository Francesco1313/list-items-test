User Groups Admin — Table Layout Prototype

Strategy 1

Title wraps up to 2 lines — variable row height

  • Title column is wider; text wraps to a maximum of 2 lines. Row height expands naturally to fit content.
  • Titles exceeding 2 lines are truncated with ellipsis; full text appears via custom tooltip on hover.
  • Tags column is narrower. Chips are truncated at ~18 characters; full label shown in tooltip on hover.
  • Variable row height — rows are not the same height across the table. ⚠ risky
Variable row height risk: Row heights differ row-by-row depending on title length. This can make the table feel visually uneven and complicates virtual-scroll / fixed-header implementations. Skeleton loading states and row striping also become harder to maintain consistently.

Strategy 2

Fixed row height (42 px) — single-line title

  • All rows share a fixed height of 42 px. No row ever grows taller than this.
  • Title column is wider; text is constrained to a single line and truncated with ellipsis. Full text shown in tooltip on hover.
  • Tags column is narrower. Chips are truncated at ~18 characters; full label shown in tooltip on hover.
  • If the title column is still too narrow for long names, the tooltip becomes the primary reading mechanism for that data. ⚠ risky
Tooltip-as-primary-reading risk: When many titles are truncated, users must hover each row to understand what they're looking at. This is especially painful on touch devices (no hover state), and reduces scannability for power users managing many groups. Consider increasing the column's minimum width or surfacing title in a secondary label.
